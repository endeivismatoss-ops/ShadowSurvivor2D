# Shadow Survivor 2D

Juego de aventura y supervivencia 2D para navegador móvil y computadora. No necesita instalar aplicaciones ni usar un servidor propio.

## Probar
1. Abre `index.html` en un navegador compatible. Si el teléfono no permite abrirlo directamente, usa GitHub Pages siguiendo los pasos de abajo.
2. Pulsa **JUGAR**.
3. En móvil, usa el joystick de la esquina inferior izquierda. El ataque al enemigo más cercano es automático.
4. Recoge orbes, sube de nivel y elige mejoras. El jefe aparece después de un rato.

## Publicar desde iPhone con GitHub Pages
1. En Safari abre https://github.com e inicia sesión.
2. Pulsa **+** y crea un repositorio nuevo llamado `ShadowSurvivor2D`. Selecciona **Public**.
3. Entra en el repositorio y usa **Add file → Upload files**.
4. Sube `index.html` desde este paquete (puedes subirlo solo; el juego funciona sin archivos externos).
5. Pulsa **Commit changes**.
6. En el repositorio abre **Settings → Pages**.
7. En **Build and deployment**, elige **Deploy from a branch**, rama `main`, carpeta `/(root)` y guarda.
8. Espera unos minutos. El enlace normalmente será `https://TU-USUARIO.github.io/ShadowSurvivor2D/` (reemplaza TU-USUARIO por tu usuario de GitHub).

## Archivos
- `index.html`: juego completo (HTML, CSS y JavaScript).
- `README.md`: estas instrucciones.

## Controles
- Móvil: joystick táctil.
- PC: WASD o flechas.
- Ataque: automático al enemigo más cercano dentro del alcance.
- Pausa: botón `Ⅱ`.
